# 09 · Glossary

- **AVFS** — Analysis, Vocabulary, Forecast, Strategy: the four-pillar core engine.
- **Round** — a single crash-curve outcome (multiplier + timestamp + metadata). Immutable.
- **Source** — a game feed, e.g. `aviator`, `skyward`, `skyward-deluxe`.
- **Ingest method** — origin of a round: `api`, `file`, `live-feed`.
- **Ladder** — banded multiplier structure used in band analysis.
- **Resistance** — statistical levels where the curve tends to stall.
- **Regime** — a detected market/behavioral state of the stream.
- **DNA** — encoded fingerprint of a pattern used for similarity matching.
- **Moonshot** — a high-multiplier outcome; the moonshot scanner detects exhaustion/opportunity.
- **Pressure** — accumulated tendency toward a state change (mega-pressure tracker).
- **Linguistics** — eight-layer semantic vocabulary describing stream behavior.
- **Orchestrator** — decision layer balancing patience, speed, risk, mistake prevention.
- **Autopilot** — paper-trading decision recorder (never places real stakes).
- **Honest accuracy** — scoring only forecasts recorded before the round landed; Brier score reported.
- **Provably-fair engine** — cryptographically verifiable round generator used for the live feed.
