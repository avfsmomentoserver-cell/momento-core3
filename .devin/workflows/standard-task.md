# Standard Task Workflow

## Stages
1. **Understand** - Read the requirements, context, and existing code
2. **Design** - Plan the implementation approach
3. **Implement** - Write the code following project standards
4. **Test** - Run tests and validate the implementation
5. **Document** - Update documentation as needed
6. **Review** - Verify the change meets acceptance criteria

## Expected Outputs
Working, tested, documented change that preserves compatibility.

## Coordinated By
Project Administrator (ag_admin)

## Default Workflow
This is the default workflow for most tasks in the project.

## Skills Integration
Uses relevant skills automatically before agent delegation.
